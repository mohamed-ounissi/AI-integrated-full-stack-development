# Diagnostic code P0128 — Coolant Thermostat Below Regulating Temperature

P0128 means the engine is taking too long to reach its normal operating temperature, or isn't reaching it at all. The most common cause by far is a thermostat stuck open.

Common causes: a stuck-open thermostat, a faulty coolant temperature sensor, or low coolant level.

Recommended first step: check the coolant level first since it's the fastest check. If coolant is at the correct level, the thermostat is the most likely cause and is a straightforward, low-cost replacement. This code is not urgent — the vehicle is safe to drive, but fuel economy and heater performance will suffer until it's fixed.
