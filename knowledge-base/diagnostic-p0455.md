# Diagnostic code P0455 — Evaporative Emission System, Large Leak Detected

P0455 means the EVAP system, which captures fuel vapor instead of letting it escape into the air, has detected a large leak — big enough that it's often something obvious.

Common causes: a loose or missing fuel cap (by far the most common cause), a cracked EVAP hose, or a faulty purge valve.

Recommended first step: always check the fuel cap first — make sure it's present, undamaged, and clicks fully closed. This alone resolves the majority of P0455 cases. If the cap is fine, the code usually clears itself after a few drive cycles once the system re-tests; a lingering code after a good cap points to a hose or valve issue.
