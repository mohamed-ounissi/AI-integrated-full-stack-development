# Diagnostic code P0171 — System Too Lean (Bank 1)

P0171 means the engine is getting more air, or less fuel, than the fuel trim calculations expect, and the ECU can't fully correct for it. "Bank 1" refers to the cylinder bank containing cylinder 1.

Common causes: a vacuum leak (cracked hose, bad intake gasket), a dirty or failing mass airflow (MAF) sensor, a weak fuel pump or clogged fuel filter, or a leaking fuel injector.

Recommended first step: check for vacuum leaks first — they're the most common cause and the cheapest to rule out. Listen for a hissing sound near the intake with the engine running, or use smoke testing if available. Only move to MAF sensor cleaning or fuel system testing once vacuum leaks are ruled out.
